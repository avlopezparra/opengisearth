      • W / S o ↑ ↓: bajar / subir la nariz
      • A / D: doblar a izquierda / derecha · N: girar más rápido (×2, ×3, ×5)
      • ← →: inclinar las alas (alabeo)
      • E / Q: acelerar / frenar
      • T / G: subir / bajar el turbo (×2 … ×100)
      • X o clic derecho: disparar (Starship)
      • R: tonel · V: rizo completo · U: media vuelta (Starship)
      • B: bomba, destruye a los enemigos cercanos (Starship)
      • + / −: acercar o alejar el minimapa · M: minimizarlo
      • P: silenciar o activar el sonido
      • L: tren de aterrizaje · F: flaps · B: frenos
      • Clic: tomar o soltar la palanca con el mouse
      • Espacio: pausa · H: ocultar el HUD · K: esta ayuda · Esc: salir
